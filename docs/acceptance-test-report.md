# GenerateView 上线验收报告

本文档记录当前生成工作台的上线验收范围、验证结果和剩余注意事项。

## 验收范围

本次验收覆盖 `/generate` 工作台：

- AI 生图：文生图、图生图、精修图、批量生成。
- 图片处理：高清放大、自由扩图、智能抠图、一键消除。
- 结果工作台：总览、精看、缩略图切换、预览弹窗、下载、局部改图、智能分层。
- 图库：最近任务、全局图库、云端同步、失败重试、部分失败重试、记录复用。
- 移动端：工具切换、紧凑结果操作、续作菜单、底部悬浮提交栏。
- 桌面端：三栏 Studio 布局、工具 rail、结果区稳定性。
- 深色模式、无障碍、无横向溢出、生产构建和包体门禁。

## 自动化验证

当前验证命令：

```powershell
pnpm test:e2e
pnpm check
```

已覆盖的关键场景：

- 桌面滚动时参数面板不被顶部导航遮挡。
- 生成提交后结果区保持加载状态直到任务完成。
- 失败任务可从最近任务和图库重试。
- 多图任务部分失败时只重试失败图片。
- 智能分层请求不携带透明背景污染参数。
- 桌面端误触工具切换时保留当前生成结果。
- 桌面端批量精看后切换工具保留当前选中结果。
- 桌面端批量结果预览可切换缩略图并复用任务参数。
- 移动端误触工具切换时保留当前生成结果。
- 移动端完成生图后可通过紧凑续作菜单带入自由扩图。
- 移动端批量生成后可从总览切到精看，并继续处理指定结果。
- 桌面和移动端没有页面级横向溢出。
- 移动端结果浮层保持在视口内，并避开底部生成栏。
- 深色模式下桌面和移动端布局稳定。
- 图片处理工具提交时携带工具类型和参数。
- 图库弹窗和图片预览弹窗没有严重无障碍问题。

## 浏览器 QA

本地浏览器 QA 使用 `/generate` 页面进行：

- 桌面视口：参数面板和结果面板并排稳定，无页面级横向溢出。
- 移动视口：AI 生图面板和高清放大面板无横向溢出。
- 移动端底部悬浮提交栏保持在视口内。
- 未启动后端时会出现 `/api/site`、`/api/models` 连接失败，这是本地环境缺少 API 服务导致，不属于前端运行时异常。

## 当前结论

生成工作台已经达到上线候选状态：

- 功能闭环完整。
- 桌面和移动布局稳定。
- 结果续作路径明确。
- 误触工具切换不会丢失结果。
- 批量生成的总览、精看和预览复用路径有端到端覆盖。
- 生产构建和 bundle 门禁可通过。

## 上线前注意事项

- 若接入真实后端，应再跑一轮联调，确认 `/api/site`、`/api/models`、`/api/generate`、图库同步和积分扣减返回结构与 mock 保持一致。
- 若调整移动端断点或底部栏高度，必须重跑 `e2e/generate-layout.spec.js`。
- 若调整预览弹窗、图库复用或结果续作，必须重跑 `e2e/generation-loading.spec.js`。
